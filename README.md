SpendWise is a functional, in-memory command-line interface (CLI) application built in Python. It provides direct terminal solutions to log daily expenditures, track categorical distributions, and check automated pricing percentages immediately.

🚀 Active Features
Live Expense Logging: Capture item descriptions, exact cash figures, and category tags dynamically.
Interactive Data Tables: View your full expense log formatted into clean, aligned terminal columns.
Real-Time Cost Aggregation: View instant updates on your total monthly expenses.
Percentage Analytics: View exact financial breakdowns to see what percentage of your money goes toward Food, Utilities, or Transport.
Runtime Crash Protection: Integrated try-except blocks protect the app from crashing if a user accidentally types text into numeric amount fields.

System Code Walkthrough

Option 1: Type your text description, enter a raw floating number for the cost, and choose category options 1 to 5.
Option 2: Displays a clean data board tracking column variables for Description, Category, and Amount along with your final sum total.
Option 3: Automates math calculation logic to convert your raw prices into clear, dynamic percentage metrics (%).
